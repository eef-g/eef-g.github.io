# Personal Portfolio Website

This is my personal portfolio website built with React. It showcases my projects, skills, and provides a way for people to contact me.

## Tech Stack

*   **React:** A JavaScript library for building user interfaces.
*   **React Router:** For handling routing within the application.
*   **Font Awesome:** Used for icons.
*   **Styled Components:** For styling components.
*   **React Helmet:** For managing changes to the document head.

## Features

*   **Homepage:** A landing page that provides a brief introduction.
*   **About Page:** A page that provides more information about me.
*   **Projects Page:** A page that showcases my projects.
*   **Contact Page:** A page with a form to contact me.
*   **Responsive Design:** The website is designed to work on all devices.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You will need `Node.js` and `git` installed globally on your machine.

### Installation

1.  Clone the repository:
    ```sh
    git clone https://github.com/your-username/your-repo-name.git
    ```
2.  Install the dependencies:
    ```sh
    npm install
    ```
3.  Run the project:
    ```sh
    npm start
    ```
    This will run the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Deployment

This project is deployed using GitHub Pages. The `deploy` script in `package.json` handles the deployment process.
